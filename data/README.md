# Dataset Directory: IMDb Movie Reviews

This directory contains raw and processed data for the **Multimodel Sentiment Analysis of Text in DL** project.

## Dataset Overview
- **Name:** IMDb Large Movie Review Dataset (Binary Sentiment Classification)
- **Total Records:** 50,000 movie reviews
- **Label Distribution:** Perfectly balanced:
  - Positive reviews: 25,000 (50.0%)
  - Negative reviews: 25,000 (50.0%)
- **Data Partitions:**
  - `data/processed/train.csv`: 35,000 reviews (70.0%)
  - `data/processed/val.csv`: 7,500 reviews (15.0%)
  - `data/processed/test.csv`: 7,500 reviews (15.0%)
- **Source:** Stanford AI IMDb Sentiment Benchmark / Kaggle public repository.
